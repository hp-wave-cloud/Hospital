# Sri Lakshmi Multi Speciality Hospital Website

A modern, responsive hospital website built with HTML5 and CSS3. The website uses a clean light-blue and white theme, presenting hospital information, services, doctors, appointments and contact details in a professional layout.

## Live Preview

Open `index.html` in any modern web browser to preview the website locally.

## Features

- Responsive design for mobile, tablet and desktop
- Hospital email and contact bar
- Full-width hospital banner
- About section highlighting healthcare experience
- Five swipeable specialty cards
- Four doctor profile cards
- 24/7 emergency care section
- Online appointment request form
- Google Reviews section
- Google Maps integration
- Telephone and email links
- Wheelchair-accessible facilities information
- Automatically wrapping contact pills and buttons
- Clean blue and white healthcare interface

## Services Featured

### Diagnostic Tests

- CT Scan

### Treatment

- Viral Fever treatment
- Skin Disease consultation

### Surgical Services

- Grommet Insertion

### Emergency and Accessibility

- 24/7 hospital support
- Dedicated emergency ward
